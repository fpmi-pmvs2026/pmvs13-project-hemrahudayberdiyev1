**Address Book** - Мобильное приложение для управления контактами

## Description
Address Book - это Android-приложение для хранения и управления списком контактов. Приложение позволяет добавлять, просматривать, редактировать и удалять контакты. Все данные сохраняются в локальной базе данных SQLite. Приложение поддерживает адаптивный интерфейс для телефонов и планшетов, использует фрагменты для навигации и соответствует принципам Material Design.

### Usage
#### Главный экран
##### При запуске открывается список всех контактов. Каждый контакт отображается в отдельной карточке.

##### Кнопки в списке контактов:

- ✏️ Edit - редактирование контакта

- 🗑️ Delete - удаление контакта

- Нажми на имя контакта для просмотра детальной информации

##### Кнопка + в правом нижнем углу - добавление нового контакта.

#### Добавление контакта
1. Нажми на кнопку +

2. Заполни поля:

- Name (Required) - имя (обязательное поле)

- Phone - номер телефона

- Email - электронная почта

- Street - улица

- City - город

- State - штат/регион

- Zip - почтовый индекс

3. Нажми Save Contact

#### Просмотр контакта
- Нажми на имя контакта в списке

- Откроется экран с полной информацией

- В верхнем меню доступны кнопки Edit (✏️) и Delete (🗑️)

#### Редактирование контакта
- Открой контакт для просмотра

- Нажми на кнопку Edit (✏️) в верхнем меню

- Измени нужные поля

- Нажми Save Contact

#### Удаление контакта
1. Открой контакт для просмотра

2. Нажми на кнопку Delete (🗑️) в верхнем меню

3. Подтверди удаление в диалоговом окне
